Use case: ui-mockup / reference-guided redesign.
输入图是用户原版 Android TV 投影仪调光应用的真实截图，是必须遵循的信息结构和功能参考，不是随意的气氛参考。请直接基于它做一次具有高级设计感、优雅苹果风的 UI 视觉升级，输出一张完整的 16:9 横屏高保真界面图。

必须保留原图的左右双栏结构：上方应用标题与退出；左侧较大的屏幕亮度区域，当前数值100%、横向滑杆、25% / 60% / 100% 三个预设；右侧保活策略区域，两个独立的操作按钮「常驻保活」「画中画保活」。这些是触发操作的按钮，不要改成开关，不增加功能，不删功能。滑杆完整范围0%到100%，绝不能引入20%的下限。保留「推荐」小标识、「开启后退出自动保持透明」、「爱奇艺/腾讯专用」的现有信息。原图Android 36这个显示保留为低优先级信息，不要虚构Android版本。只做视觉设计，不重新定义操作逻辑。

审美方向：以真正的 Apple TV / macOS 深色模式和 Apple 产品界面的精确工艺为标准。原图的深色氛围保留，但要明显更考究、更清晰、更有呼吸感。使用精致的石墨灰半透明材质、很细的边缘高光、柔和真实的层级阴影、低饱和冰蓝点缀、清晰的近白文字。大标题与亮度数字有准确的字重对比，中文像苹方一样干净，克制、有留白、有对齐秩序。把原图的emoji替换为统一的精美细线符号，像SF Symbols那样。减少冗余嵌套边框和原图过肥的胶囊按钮；面板圆角、按钮圆角、间距有一致的比例关系。不要把“苹果风”做成白色表单或无设计的系统设置列表，不要金色影院皮肤、射灯、帷幕、彩色大光晕或廉价霓虹。

发挥专业视觉设计判断：保持双栏信息架构，但重新校准整个面板的比例、标题区高度、左右卡片内的层次与视觉重心。左侧亮度区是视觉主角，右侧操作更安静有序。用优雅的排版和精致控件形成质感，而非堆装饰。让电视上的焦点选择清楚可见：只为100%预设表现一个精致的浅色聚焦面，其他按钮保持安静。所有内容一屏展示，适合客厅远距离观看和遥控器操作。设计必须成熟，像可真正交付的原生TV应用。

必须准确呈现的文字：亮度调节、Android 36、退出、屏幕亮度、100%、遥控器左右微调、25%、60%、100%、保活策略、常驻保活、推荐、开启后退出自动保持透明、画中画保活、爱奇艺/腾讯专用。可在滑杆下低调标示0%与100%端点。
输出纯UI画面，无电视外框、透视、房间、网页展示样机、设计说明、前后对比或水印。
